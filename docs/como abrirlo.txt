      GESTOR DE TERRITORIOS TELEFÓNICOS
===================================================

¿CÓMO INICIAR LA APLICACIÓN?

Paso 0 (Solo la primera vez):
  - Haz doble clic sobre "scripts\instalar.bat".
  - Esto crea el entorno virtual e instala las librerias necesarias.

Paso 1 (Siempre):
  - Haz doble clic sobre "scripts\iniciar_app.bat".
  - Se abrira la consola y automaticamente tu navegador en http://127.0.0.1:5000
  - Si no existe el entorno virtual, te pedira que ejecutes instalar.bat primero.

Alternativa (Desde la terminal / PowerShell):
  1. Abre la terminal en esta carpeta.
  2. Primera vez, crea el entorno e instala dependencias:
        python -m venv venv
        venv\Scripts\python.exe -m pip install -r requirements.txt
  3. Ejecuta:
        venv\Scripts\python.exe app.py
  4. Abre tu navegador web e ingresa a:
        http://127.0.0.1:5000

ESTRUCTURA DE CARPETAS:
  - app.py: Código principal del servidor.
  - database.py: Conexión a la base de datos SQLite (territorios.db).
  - templates/: Plantillas HTML de la interfaz.
  - static/: Archivos de diseño CSS y estilos.
  - scripts/: Scripts de instalación y arranque.
  - docs/: Documentación y archivos de referencia.
  - exports/: Módulos de exportación (PDF, PNG, Excel).

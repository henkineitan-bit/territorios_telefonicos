Formato esperado

La primera fila del Excel tiene que ser el encabezado, con estas columnas (el orden no importa, pero los nombres sí):

  • numero — obligatorio (número del territorio)
  • telefono — obligatorio
  • direccion — opcional
  • observaciones — opcional
  • no_llamar — opcional (si / no / 1 / 0, vacío = no)
  • funcionan — opcional (si / no / 1 / 0, vacío = sin verificar)
  • notas_internas — opcional

Si el territorio ya existe (mismo número), no se duplica. Si el registro telefónico ya existe (misma dirección + teléfono en ese territorio), se actualiza en vez de crear uno nuevo.
